## 📁 CẤU TRÚC HỆ THỐNG TÀI LIỆU DOANH NGHIỆP (/docs)
Bộ tài liệu chuẩn hóa được phân cấp thành 4 phân hệ chuyên biệt (xem chi tiết tại [docs/README.md](./docs/README.md)):

1. [branding/](./docs/branding/): Ý nghĩa tên gọi 3 âm tiết SynapForge, Hệ thống Slogan, Lưới 8pt Swiss Grid, Glassmorphism & Mô hình bánh đà kép.
2. [ventures/](./docs/ventures/): 2 Trụ cột sản phẩm hạt giống cốt lõi: BrandHub (AI MarTech 7 Microservices) & BienSoVip (.NET 8 CSDL 61 bảng).
3. [standards/](./docs/standards/): Tiêu chuẩn xuất xưởng phần mềm: Clean Architecture (.NET 8 & Java 21), RabbitMQ DLQ + Transactional Outbox, OWASP Top 10 & Sổ tay chỉ mục CSDL.
4. [website/](./docs/website/): Đặc tả chức năng, UX flow, Interactive Estimator, Synapse Canvas & Lộ trình 4 Sprints hoàn thiện Website chính thức.

## 🚀 CẤU TRÚC SOURCE CODE WEBSITE REACT (/src)
Mã nguồn website chính thức được khởi tạo sẵn sàng cho team phát triển:
- `src/components/`: Các components giao diện dùng chung (Header, Footer, Button, Card...)
- `src/pages/`: Các trang chính (Home, Ventures, Services, Team, Estimator...)
- `src/data/`: Chuyển hóa toàn bộ dữ liệu công ty và team từ markdown sang JSON/JS models.
- `src/assets/`: Chứa Logo nhận diện thương hiệu, hình ảnh team và sản phẩm.
