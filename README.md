## 🚀 CẤU TRÚC SOURCE CODE WEBSITE REACT (/src)
Mã nguồn website chính thức được khởi tạo sẵn sàng cho team phát triển:
- `src/components/`: Các components giao diện dùng chung (Header, Footer, Button, Card...)
- `src/pages/`: Các trang chính (Home, Ventures, Services, Team, Estimator...)
- `src/data/`: Chuyển hóa toàn bộ dữ liệu công ty và team từ markdown sang JSON/JS models.
- `src/assets/`: Chứa Logo nhận diện thương hiệu, hình ảnh team và sản phẩm.
